# 📋 Daily Task Manager

> A clean, minimalist, and efficient tool to help you organize your daily routines, manage tasks, and track your progress effortlessly.

This project is a lightweight, responsive task management application designed for seamless daily productivity.

🔗 **Live Demo:** [View Task Manager](https://task-manager-r2iw.vercel.app/)

---

## ✨ Features

- 📝 **Task Creation:** Quickly add, edit, and organize your daily tasks.
- ✅ **Task Tracking:** Easily monitor your productivity with real-time tracking of pending and completed tasks.
- 🎯 **Empty State Handling:** Intuitive interface design for when your task list is clear.
- 📱 **Responsive Design:** Optimized for a seamless experience on mobile, tablet, and desktop devices.
- 🌐 **RTL Support:** Fully optimized for Right-to-Left languages.

---

## 🛠️ Built With

- **Frontend:** React.js / JavaScript
- **Styling:** Tailwind CSS / CSS
- **Deployment:** Vercel
